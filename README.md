# Como rodar o projeto?

- No terminal rode:
```npm install```

- Criar o arquivo *.env*:
```touch .env```

- Inserir a sua KEY da API:
```VITE_API_KEY=coloque_sua_chave_aqui```

- Por fim, rode:
```npm run dev```
